# 实验记录提交范式：

---

# XXX实验结果

## Objectives

你的实验目的

## Methods

大概概括说明一下实验用的方法，不用像Protocol一样细致。

## Result

凝胶电泳图，SDS-page图，绘制的OD600曲线等等。为了避免实验后期整理实验记录时，需要重复修改你实验结果图，所以如果你的实验结果需要涉及到标注图片，你的所有图例最好用英文注释。

---

# 实验记录提交要求

1、格式要求：

 #一级标题 **写xxx实验结果** eg.*巢式PCR提取asc基因实验结果/质粒构建结果/验证XXX蛋白表达实验结果*

##二级标题 Objectives、Methods、Result

2、同protocol，需文件名写上你的名字，以记录你对团队的工作贡献。eg. YH-XXX实验结果

3、你可以用中文写，但需要你把你的文档翻译成英文版附在中文版后面，整合为一个md文件上传github。

# SDX-01 表面展示平台文献比较实验结果

## Objectives

为大肠杆菌表面展示纤维素酶选择合适的锚定平台（anchor platform）。核心约束：目标 cargo（Cel48S / Cel9K / Cel5L）分子量较大，锚定系统需在不破坏酶活的前提下将其稳定展示于细胞外膜（2026.4.17–5.15）。

## Methods

文献调研，比较三类常见的大肠杆菌表面展示策略——Lpp-OmpA、SpyTag/SpyCatcher 与 INP（冰核蛋白）。评价维度：融合蛋白大小适应性、折叠可行性、质粒负担、对高分子量 cellulase 的展示可行性。

## Result

**选定 INP（Ice Nucleation Protein）路线**：对大分子量 cargo 的适应性最好，且无需额外组分共表达，系统复杂度最低。Lpp-OmpA 因融合结构对 cargo 折叠限制较大而保留为备选方案（该备选后来在 DBTL B5 中正式启用）；SpyTag/SpyCatcher 需两套组分共表达，弃用。

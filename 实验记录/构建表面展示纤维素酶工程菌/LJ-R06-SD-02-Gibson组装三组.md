# SD-02 Gibson Assembly 三组实验结果

## Objectives

构建 pCDF–INPNC–Cel48S / Cel9K / Cel5L 三个重组质粒（2026.7.28）。

## Methods

将线性化 pCDF 载体（CloDF13 / SmR）与 INPNC、linker 及各 cellulase 片段按载体 : 插入 = 1 : 2–3 的摩尔比进行 Gibson Assembly，三组反应分别对应三个 cargo；产物保留 aliquot 供后续验证。

## Result

获得三个 assembly mixtures。需要注意的是，此时尚未通过测序确认其中是否存在完整、正确、可复制的环状重组质粒——产物仍是“混合物”。这一“组装与转化必须拆开判断”的认识，后来成为 SD-04 / SD-05 分歧结果的关键判据。

# SD-09 链霉素 + 壮观霉素双抗平板 WT 对照实验结果

## Objectives

检验双抗生素组合能否提高筛选严谨性（2026.8.28–8.29）。

## Methods

制备链霉素 + 壮观霉素双药平板，将工程菌与 DH5α WT 分别涂布，37 ℃ 过夜培养。

## Result

WT 在双抗平板上仍能形成 colonies。连续三种筛选条件下 WT 均生长，说明 SmR-based 筛选体系整体无法承担筛选功能，予以弃用；下一轮更换为 pACYC / 氯霉素体系。

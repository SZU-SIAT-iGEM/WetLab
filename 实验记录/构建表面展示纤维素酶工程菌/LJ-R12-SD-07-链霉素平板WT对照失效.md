# SD-07 链霉素平板 WT 对照实验结果

## Objectives

检验链霉素平板能否抑制未转化的 WT，判断 SmR 筛选是否有效（2026.8.7–8.8）。

## Methods

将转入 pCDF-based SmR 质粒的工程菌与未经 transformation 的 DH5α WT 分别涂布于链霉素平板，37 ℃ 过夜培养。

## Result

工程菌与 WT 均能形成单菌落——链霉素单抗生素条件无法抑制 WT，不能区分 WT 与携带质粒的细胞。这解释了 SD-03 / SD-04 的疑团：第一代“转化子”很可能只是背景生长。

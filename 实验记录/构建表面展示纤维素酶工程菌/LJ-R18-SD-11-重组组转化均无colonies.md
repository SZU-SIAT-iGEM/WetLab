# SD-11 三个重组组转化实验结果

## Objectives

在三层 baseline 成立的前提下，获得三个 pACYC 重组体系的转化子（2026.9.24）。

## Methods

按 SDX-07 引物重新扩增片段，分别完成三个 INPNC-cellulase 组分的 Gibson 组装（三构建共用同一线性化骨架与 INPNC-Linker 锚定模块，启动子相同，仅 cargo 不同）并转化 MG1655，氯霉素筛选。

## Result

三个重组组均未获得预期 colonies（INPNC-Cel5L / Cel9K / Cel48S 全部为 no colony）。在 SD-10 已证明筛选、宿主、骨架均正常的前提下，失败呈现明显的 construct-dependent 模式；三个仅 cargo 不同的构造出现相似失败，更值得测试的假设是共享结构带来的细胞负担。但在得出表达负担结论之前，必须先排除“三个重组构建再次组装失败”（→ SD-12）。

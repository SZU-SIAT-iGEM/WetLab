# SD-08 壮观霉素平板 WT 对照实验结果

## Objectives

检验更换为壮观霉素后能否建立 WT 与转化子之间清晰的生长差异（2026.8.19–8.20）。

## Methods

重新购买壮观霉素并制备筛选平板，将工程菌与未经 transformation 的 DH5α WT 分别涂布，37 ℃ 过夜培养。

## Result

工程菌与 WT 均能形成 colonies——壮观霉素单药同样无法抑制 WT，说明问题并非由某一种抗生素或某一批平板造成。

# DBTL Cycle1：基于 asc 操纵子的质粒设计与工程菌构建

## Overview

我们希望解决微重力环境下弱传质导致的底物接触效率下降问题。在微重力环境下，液体对流显著减弱，纤维素降解后产生的可溶性糖难以快速扩散到远处，因此我们希望工程化大肠杆菌，使其能够感知并趋向纤维素降解产生的可溶性糖信号，从而主动靠近固体底物，提高局部接触和降解效率。

在第一轮设计中，我们选择了大肠杆菌自身基因组中存在的 `asc` 系统作为工程化对象。`asc` 操纵子与部分 β-葡萄糖苷类糖的转运和代谢有关，其中：

- `ascF` 编码与糖转运相关的膜蛋白；
- `ascB` 编码 β-葡萄糖苷酶，参与胞内后续代谢。

我们的目的是将目标基因（`ascF`、`ascB`）克隆至合适的表达载体，转化至大肠杆菌MG1655底盘，并获得可稳定传代、可诱导/组成型表达的工程菌株。

整个Cycle 1被拆分为四个子循环（Cycle 1.1–1.4），从质粒设计逐步推进至工程菌株构建完成。

## Cycle 1.1 质粒设计与表达盒构建策略

### Design｜设计

在质粒设计上，我们的主要设计决策点如下表所示：

| 决策项  | 最终选择                    | 备注                                             |
| ---- | ----------------------- | ---------------------------------------------- |
| 底盘菌株 | *E. coli* MG1655        | F- lambda- ilvG- rfb-50 rph-1                  |
| 载体骨架 | pGEX-4T-1               | pBR322 ori（中低拷贝），AmpR抗性                        |
| MCS  | BamHI + EcoRI           | BamHI (GGATCC) 5'端，EcoRI (GAATTC) 3'端          |
| 启动子  | J23116                  | 组成型弱启动子，强度为BBa_J23100的0.16倍                    |
| 终止子  | BBa_B0015               | 强双终止子，放置在最后一个基因的下游                             |
| RBS  | BBa_B0034               | 序列：AAAGAGGAGAAA，每个CDS前各放置一个                    |
| 基因来源 | 野生型 *E. coli* MG1655基因组 | 无密码子优化、无标签                                     |
| 融合方式 | 双顺反子                    | [J23116]—[B0034]—[ascF]—[B0034]—[ascB]—[B0015] |
| 对照设计 | 空载体（EV）                 | 将终止子直接合成在载体内                                   |

同时使用 SnapGene 设计 Gibson Assembly 所需的同源臂及巢式PCR引物，并设计四对测序引物用于后续验证。对于人工设计的引物，我们用 NCBI 的 Primer-blast 功能检查引物的各项指标是否符合要求：整体自互补性 Self complementarity，<8为安全范围，10往上可能形成2级结构影响结合；Self 3' complementarity 影响结合效率，≤ 3 为安全范围。

### Build｜构建

根据设计合成引物；使用 BamHI/EcoRI 的 Fastdigest 试剂双酶切制备线性化载体。

### Test｜测试

序列验证：通过SnapGene模拟组装，检查确认同源臂设计正确、质粒物理图谱合理。

引物验证：经 NCBI Primer-blast 验证，各项指标均符合要求。

### Learn｜学习

本轮的引物完全使用 SnapGene 由人工手动设计，虽然最终通过了 Primer-blast 的指标检查，但过程较为耗时。相比之下，利用NCBI的 Primer-Blast 在线工具或基于AI的引物设计辅助平台（如Primer3Plus、Benchling等）能够更快速地生成候选引物，并自动优化多组参数，减少人工试错成本。因此，我们可以尝试使用这些工具辅助引物设计，以提高效率，缩短设计周期。

## Cycle 1.2 目的基因扩增与同源臂悬挂

### Design｜设计

采用巢式PCR从野生型 *E. coli* MG1655 基因组中提取 ascF 和 ascB 基因。第一轮使用外侧引物扩增包含基因上下游各约500 bp侧翼序列的长片段；第二轮使用内侧引物扩增基因编码区（CDS）。随后通过 Touchdown PCR 分别在 ascF 基因前悬挂 Promoter-RBS 同源臂（Fragment 1），在 ascB 基因前悬挂 MidRBS-Spacer 同源臂（Fragment 2），为后续Gibson组装准备插入片段。

### Build｜构建

按设计体系进行两轮巢式 PCR 扩增获得基因片段，再以巢式 PCR 第二轮产物为模板进行 Touchdown PCR 悬挂同源臂，并进行最终产物的纯化回收。

### Test｜测试

巢式第一轮 PCR：以 MG1655 基因组 DNA 为模板，使用外侧引物扩增包含基因上下游各约 500 bp 侧翼序列的长片段。电泳结果显示，ascF 和 ascB 均在约 2500 bp 处出现单一、明亮的特异性条带，与预期大小一致，无非特异性扩增或引物二聚体，说明第一轮扩增成功，模板质量良好。

### Learn｜学习

两轮巢式PCR成功从基因组中获得了目的基因片段，Touchdown PCR 也成功悬挂了同源臂。两个片段均可用于下一步纯化和Gibson组装。但值得注意的是，Fragment 1 和Fragment 2 的长度相近，在电泳中难以区分，后续胶回收和定量时需特别注意标记清晰，避免混淆。

## Cycle 1.3：DH5α克隆筛选与测序验证

### Design｜设计

将 Cycle 1.2 获得的两个片段与线性化载体进行Gibson Assembly，构建重组质粒。组装产物转化 DH5α 感受态细胞，涂布氨苄青霉素平板进行抗性筛选。挑取单克隆进行扩培，使用四对测序引物进行菌落PCR，覆盖表达盒四个相邻区段，以筛选阳性克隆。

### Build｜构建

按无缝克隆试剂盒推荐比例配制 Gibson 组装体系（载体100 ng + Fragment 1 + Fragment 2，2× CE Mix V3补至10 μL），50℃ 反应15–30 min。产物转化 DH5α 感受态细胞，复苏后涂布氨苄平板，37℃过夜培养。挑取单克隆扩培后以四对测序引物进行菌落PCR，每对引物预期产物约750 bp。

### Test｜测试

复苏后的 DH5α 感受态细胞共接种了6个平板，其中4个涂布接种了工程菌（含重组质粒），浓度进行了梯度稀释；剩余2个划线接种了空载对照（仅含载体骨架＋终止子）。

过夜培养后，工程菌平板长出单菌落，而空载对照也长出菌落，表明氨苄抗性筛选有效。梯度稀释平板上的菌落密度相较于未稀释平板来说更小。

电泳结果显示：样品 2‑1、3‑1、3‑2、4‑1 在四对引物下均扩增出清晰、大小正确的目的条带，且无额外非特异条带；样品 1‑1、1‑2、2‑2 部分引物对无条带或条带较弱，可能为假阳性或质粒结构不完整。

### Learn｜学习

在初期挑取单克隆时，我们习惯性地选择了较小的菌落进行扩培，但过夜培养后，含氨苄青霉素的液体 LB 培养基并未变浑浊。起初我们怀疑是转化失败或抗生素失效，但经过查询资料和重新检查平板后发现，氨苄平板上容易出现“卫星菌落”，即主菌落周围的微小菌落，它们可能因β-内酰胺酶降解了周围抗生素而得以生长，但本身并不携带完整质粒或仅为非抗性突变株。

随后，我们重新挑选了形态饱满、孤立的主菌落进行扩培，过夜培养后菌液明显变浑浊，且菌落PCR能扩增出正确大小的目的条带。这一教训提醒我们，在氨苄抗性筛选中，必须注意区分真阳性克隆与卫星菌落，应优先挑选较大、孤立、边缘整齐的菌落，并在挑取后通过液体培养浊度和PCR双重确认，避免假阴性或假阳性干扰后续实验。

## Cycle 1.4：MG1655 转化与工程菌验证

### Design｜设计

将测序验证正确的重组质粒从 DH5α 中提取出来，转化至最终底盘 *E. coli* MG1655 感受态细胞。涂布氨苄平板筛选阳性克隆，并使用一对跨整个表达盒的通用引物进行菌落PCR，验证质粒是否成功转入且插入片段完整。

### Build｜构建

使用质粒提取试剂盒从DH5α阳性克隆（2-1和3-2）中提取重组质粒，转化MG1655 感受态细胞，复苏后涂布氨苄平板，37℃过夜培养。挑取单克隆扩培，使用通用引物进行菌落PCR，预期产物约3000 bp。

### Test｜测试

将复苏后的感受态细胞涂布氨苄平板后，工程菌和空载对照均生长出适量单菌落，稀释平板菌落分布均匀，未稀释平板菌落密集但可辨认。

<img width="2487" height="2476" alt="MG1655-asc" src="https://github.com/user-attachments/assets/ea58e4be-2ce5-4b3c-b3df-69e8d1157d6f" />

图1-8：MG1655平板筛选结果

分别从工程菌和空载平板上各挑取 2 个单克隆，使用一对跨整个表达盒的通用引物进行菌落 PCR。该通用引物能够扩增覆盖从启动子到终止子的全长插入片段，预期约 3000 bp。

电泳结果显示：工程菌四个克隆均在约 3000 bp 处出现明显的单一目的条带，与理论大小吻合，仅有一条条带亮度较弱；空载对照克隆在对应位置无任何条带。

该结果证实重组质粒已成功转入 MG1655，且插入片段完整未发生重组丢失。至此，工程菌株构建完成，可用于后续功能测试。

### Learn｜学习

在本轮循环中，我们使用了一对跨整个表达盒的通用引物进行菌落 PCR，扩增产物约3000 bp。我们选择先以多对短引物在 DH5α 中进行初筛锁定候选克隆，再用长片段引物在最终底盘 MG1655 中进行确认性验证，形成多对短引物初筛 + 一对长引物终验的组合策略，提高了在最终底盘中的验证效率。

以上结果可以说明，重组质粒已成功转入MG1655，插入片段完整未发生重组丢失，工程菌株构建完成。但 Cycle 1 的完成仅限于DNA构建层面，我们尚无法回答以下问题：AscF和AscB是否在蛋白水平表达？表达量是多少？两个基因的表达是否均衡？膜蛋白是否正确定位？工程菌是否获得了增强的纤维二糖转运能力或趋化表型？这些功能验证问题将交由Cycle 2回答。

# DBTL Cycle 3：chb 启动子梯度菌株的纤维二糖摄取定量（DNS 法）

## Design｜设计

Cycle 2 中我们用 CP12 与 WT 的对比确认了 chb 构建能产生可定量的纤维二糖摄取。本轮把问题从"有没有摄取"推进到"不同表达强度下摄取差多少"：我们将 6 株 CP 系列启动子工程菌（CP6、CP7、CP12、CP25、CP30、CP44）与 WT 放在同一静息细胞体系（PBS + 1 mM cellobiose）中，以 DNS 法测定上清剩余纤维二糖在 15/30/60 min 的变化，每株 3 个生物学重复，建立"启动子 → 摄取能力"的定量排序。

我们的预期是：WT 基本不消耗，CP 菌株的消耗速率应随 chb 表达强度拉开梯度。

## Build｜构建

各株取 3 个独立单克隆作为生物学重复，M9 + 0.2% glycerol 预培养后收菌洗涤，重悬于 PBS + 1 mM cellobiose（原始菌悬液与 2 mM 纤维二糖 1:1 混合）。到点整管离心取上清，175 μL 上清 + 125 μL 试剂二沸水浴 5 min，96 孔板 540 nm 读数，标准品为自配纤维二糖梯度。详细步骤见《DNS法纤维二糖摄取检测Protocol（7菌株正式实验）》。

实际执行中的偏离：CP44、CP25、CP30 的中间时间点实际取在 45 min；技术重复第二孔因体积不足 200 μL 而系统性偏低，分析时只保留每对的第一孔；WT 重复 3 的 30/60 min 与 CP44 重复 3 的 45/60 min 为明显异常点，已从主分析剔除（原始值保留在实验记录中）；各组起始细胞浓度未统一，实测体系内 OD600 为 1.39–2.86（WT 最高，CP7 最低），摄取速率按实测 OD600 归一化后比较（见 Test 4）。

## Learn｜学习

### Learn 1：启动子梯度成功转化为摄取能力梯度

除 CP6 外，所有 CP 菌株的 60 min 剩余糖均显著低于 WT，chb 表达强度的差异确实转化成了可分辨的摄取表型差异，这条定量链条成立，可以进入与趋化性能的关联分析。

### Learn 2：归一化后显著摄取集中在 CP12、CP7 与 CP30

按实测 OD600 归一化后，CP6、CP25、CP44 与 WT 的差异不再显著（p = 0.095 / 0.068 / 0.057）——它们归一化前的显著性有相当成分来自细胞量差异。CP7 细胞量最低但单位细胞摄取速率与 CP12 持平，归一化前被低估。后续比较"启动子强度 → 摄取能力"必须以单位细胞速率为准，并尽量统一起始 OD600。

### Learn 3：当前体系对强株分辨不足，需要重新标定动态范围

CP12 在 30 min 时体系已接近耗尽，CP12 与 CP30 的多个点落在试剂盒线性下限（0.1 mg/mL）以下，我们只能判断"谁更强"，还无法准确回答"强多少"。下一轮对强株改用 5/10/20 min 时间点，或降低细胞浓度、提高底物浓度，把摄取速率测进线性区间。

### Learn 4：缺少 t = 0 和同板空白限制了绝对定量

WT 15 min 的绝对值（≈0.26 mg/mL）低于名义初始浓度 0.342 mg/mL，本轮无法区分配液偏差、背景扣除过度还是早期摄取；这也使 WT 在归一化速率中出现约 0.0015 的表观值——以 WT 15 min 实测均值（0.262 mg/mL）为有效 C0 重算后 WT 回到近零，且各株排序不变。下一轮每板自带标准曲线与空白，并为每个生物学重复加 t = 0 管。此外标准曲线低端存在轻度非线性，浓样品应稀释后复测。

### Learn 5：DNS 只报告总还原糖

剩余糖的身份以及摄取产物仍需 HPLC/HPAEC-PAD 确认，与 Cycle 1 设定的方向一致。

## Redesign｜下一轮

1. 强株（CP12、CP30）用 5/10/20 min 短时间点重做，弱株（CP6、CP7、CP25、CP44）保留 15/30/60 min；
2. 每株加 t = 0 管，每板带标准曲线与空白；
3. 统一各组起始 OD600（本轮 1.4–2.9 的差异已迫使事后归一化）；在多个纤维二糖浓度下测定，计算单位细胞摄取速率 q(C)，拟合动力学参数；
4. 将摄取速率排序与 RT-qPCR 测得的 chb 表达量、软琼脂趋化结果关联，验证"表达强度 → 摄取速率 → 趋化性能"的定量链条。

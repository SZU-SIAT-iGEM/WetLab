# 纤维二糖趋化性验证 DBTL

## Overview

在完成 `ascFB` 工程菌构建后，我们希望进一步验证：将 `ascB` 基因与 `ascF` 基因引入大肠杆菌 MG1655 后，工程菌是否会对纤维二糖表现出趋化性。

围绕这一问题，我们首先采用软琼脂游泳法进行初步尝试，随后根据实验结果逐步调整实验条件，并最终引入时间更短的硬琼脂塞趋化实验。经过多个 cycle 的迭代，我们不仅建立了用于观察菌落活动范围的 TTC 显色方法，也逐步把问题聚焦到 `asc` 系统本身需要其他基因组协助这一关键限制上。

---

# Cycle 1｜软琼脂游泳法的初步尝试

## Design｜设计

本轮的实验目标是验证引入 `ascB` 基因与 `ascF` 基因的工程菌 MG1655 是否会对纤维二糖表现出趋化性。为此，我们查阅相关文献，设计并采用了软琼脂游泳法。

## Build｜实施

我们设计了三种琼脂平板作为测试体系：

- 不含营养的空白 PBS 对照板；
- 以纤维二糖为唯一营养的实验组 PBS 平板；
- 以葡萄糖为唯一营养的阳性对照 PBS 平板。

同时，我们以空载菌和工程菌互为对照，通过比较两种菌落各自在三块平板上生长环的大小，来判断它们的趋化能力是否存在差异。

**创新点**：在整理软琼脂法基础实验的过程中，我们发现仅依靠细菌自身产生的趋化环，其显色能力较为有限。因此，在查阅多方资料后，我们引入了 TTC 试剂（2,3,5‑三苯基氯化四氮唑）作为显色剂。

## Test｜测试

过夜培养后，所有平板上均未长出菌落，也未观察到 TTC 发生氧化还原反应而呈现显色现象。

## Learn｜学习

这一轮实验没有达到预期。我们归纳了几种可能的原因：

1. TTC 本身具有较弱的毒性，可能对生存负荷较大的工程菌与空载菌产生了不利影响；
2. TTC 遇光容易分解，同时菌落生长速度极慢，因此未观察到明显现象；
3. 离心机的离心速度过高，可能甩断了菌的鞭毛，导致菌体无法正常活动或存活；
4. 接种环过细，接种菌液浓度较低，导致接种量偏少；
5. 菌落无法在实验平板上长时间生长，或者菌落生长速度过慢。

带着这些疑问，我们进入下一个 cycle，准备进一步验证工程菌对纤维二糖的趋化性。

---

# Cycle 2｜排查软琼脂实验失败原因

## Design｜设计

本轮实验用于验证上一 cycle 中归纳出的问题。我们设计了 3 类验证实验，依次排查可能造成实验失败的原因。

## Build｜实施

1. 验证 TTC 是否分解：取出一块琼脂板，并在上面滴加维生素 C 溶液；
2. 验证 TTC 是否会对菌落产生影响：将 TTC 直接滴入菌液中培养；
3. 验证是否是离心机转速过大所致：调低转速，重新培养菌液并重新进行实验；
4. 验证接种浓度是否偏低：调高菌液浓度，其余操作与第 3 项相同；
5. 验证菌落是否无法长时间在平板上生长：在第 3、4 项实验进行的同时进行观察。

## Test｜测试

1. 琼脂板变红，说明 TTC 并未完全分解；
2. 菌液变红，说明 TTC 的毒性不会对菌落产生显著影响；
3. 过夜培养后，平板上没有菌落生长；
4. 过夜培养后，平板上没有菌落生长。

## Learn｜学习

我们与其他组交流后得出结论：由于实验体系中未添加氮源，同时负载质粒的菌株生存压力较大，菌落无法在平板上长时间生长，因此需要缩短实验时长。

由于本次软琼脂实验未能形成菌落或游泳扩散圈，实验结果还不足以支持判断 `ascBF` 是否对纤维二糖产生额外的趋化作用，需要进一步补充实验。

同时，本轮实验确认了可以利用 TTC 来验证菌落的活性与活动范围，因此将这一方法加入后续实验。

---

# Cycle 3｜改用 M9 培养基平板

## Design｜设计

基于 Cycle 2 中发现的未添加氮源问题，我们将底盘平板由纯 PBS 平板替换为 M9 培养基平板，重新进行实验。

## Build｜实施

我们重新设计了三种琼脂平板：

- 不含营养的空白 M9 对照板；
- 以纤维二糖为唯一营养的实验组 M9 平板；
- 以葡萄糖为唯一营养的阳性对照 M9 平板。

同时，我们用空载菌和工程菌进行对照，通过比较两种菌落各自在三块平板上生长环的大小，来判断它们的趋化能力是否存在差异。

本次实验未加入 TTC，并采用双菌平行对照。

## Test｜测试

仅在葡萄糖平板上观察到菌落生长环，分别来自 `ascBF` 工程菌与空载菌；其余平板上均没有菌落生长。

## Learn｜学习

本轮实验可以得出以下结论：菌落暂时无法直接以纤维二糖作为唯一碳源进行利用，也难以在纯纤维二糖平板上长时间生长。

因此，本次实验无法直接验证工程菌是否对纤维二糖具有趋化作用，后续实验需要进一步缩短实验时间。

---

# Cycle 4｜硬琼脂 t-HAP 趋化实验初尝试

## Design｜设计

由于需要压缩实验的窗口期，我们重新查阅文献，并将实验替换为时间更短、约为 3 h 的硬琼脂 t-HAP 实验。

## Build｜实施

我们设计了 3 种硬琼脂塞配方：

- 无添加的纯 PBS‑琼脂；
- 加入纤维二糖的琼脂；
- 加入葡萄糖的琼脂。

同时，本轮继承上一 cycle 的实验结论，继续采用 TTC 作为显色剂。

## Test｜测试

由于琼脂体系黏度过高，无法顺利倒出，塞子无法成型，这一轮实验失败。

## Learn｜学习

高浓度琼脂导致体系在操作温度下过早凝固，无法顺利与纤维二糖溶液和 TTC 溶液均匀混合，更无法倒入模具。这说明 4% 琼脂母液并不适合本趋化实验的塞子制备流程。下一轮将把最终琼脂浓度下调至约 1.5%，并改为使用 2% 琼脂母液。

---

# Cycle 5｜降低琼脂浓度并补充低营养对照

## Design｜设计

基于 Cycle 4 的结果，本轮重新设计塞子配方，降低琼脂母液浓度。

同时，结合软琼脂平板趋化实验的失败经历，我们经过讨论，决定增设一组为菌落提供最低营养限度的平板，即加入低浓度的胰蛋白胨。

## Build｜实施

按照 Cycle 4 设计的琼脂塞对照组进行制备，但将琼脂塞母液浓度降低为 2%。

同时设置两组平板：

- 无营养组的菌落‑琼脂平板；
- 低营养组的菌落‑琼脂平板。

## Test｜测试

本轮完成了低营养组实验，无营养组尚未开展。结果如下：

| 平板编号 | 塞子  | 菌株    | 反应                           |
| ---- | --- | ----- | ---------------------------- |
| 1    | Glc | ascBF | 3 h 后塞周出现一圈变红，过夜培养后半径扩大、红色加深 |
| 2    | Glc | EV    | 3 h 后塞周出现一圈变红，过夜培养后半径扩大、红色加深 |
| 3    | Cel | ascBF | 无明显变化                        |
| 4    | Cel | EV    | 无明显变化                        |
| 5    | 空白  | ascBF | 无明显变化                        |
| 6    | 空白  | EV    | 无明显变化                        |

## Learn｜学习

1. 葡萄糖塞子在 `ascBF` 和 `EV` 中均出现随时间扩大的红色区域，说明 TTC‑琼脂体系能够正常指示细菌的趋化聚集，并且两种菌株的趋化能力没有受到明显损害。
2. 在低营养条件下，纤维二糖塞子和空白塞子在 `ascBF` 和 `EV` 中未观察到明显红色区域。结合 Cycle 1、Cycle 2 的实验结果，可以判断 `ascBF` 基因的引入对趋化纤维二糖并没有特别显著的效果。

# Redesign｜从 asc 系统转向 chb 系统

经历 4 次 cycle 后，我们发现仅凭 `ascBF` 基因对纤维二糖的趋化效果并不理想。为了厘清背后的原因，我们重新查阅了纤维二糖摄取与趋化信号通路的相关文献。研究发现，`asc` 系统与 `chb` 系统在纤维二糖的转运与磷酸化过程中存在密切的功能关联。从 PTS（磷酸烯醇丙酮酸依赖性磷酸转移酶系统）的组成来看，纤维二糖的跨膜转运需要酶 II 复合物的参与，其中 IIC 结构域构成膜内的转运通道，负责底物的识别与易位。`ascF` 基因编码的是一个 β-葡萄糖苷特异性的 PTS 酶 II 组分，属于 EIICB 型融合蛋白，在单独存在时其 IIC 结构域的底物结合与转运效率有限。而 `chb` 操纵子中的 `chbC` 基因编码的 ChbC 蛋白恰恰是壳二糖 PTS 的整合膜组分，含有预测的糖结合位点，其 IIC 结构域能够为纤维二糖提供高效的膜转运通道。换言之，`asc` 系统在趋化信号通路中缺少一个关键的膜转运蛋白组分，导致 PTS 系统对纤维二糖的磷酸化与摄取效率显著下降。`chb` 基因组的协助正是通过补全这一功能缺口，使纤维二糖的膜转运和后续趋化信号的触发得以高效进行。基于这一机制层面的认识，我们调整了下一步的实验方向，准备将部分 `chb` 基因组的相关基因引入大肠杆菌。

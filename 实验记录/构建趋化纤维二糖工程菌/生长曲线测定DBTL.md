# DBTL Cycle 1：ascFB 功能验证系列实验


## 1.1 以OD值反映生长曲线的测定

**Goal：** 验证 pGEX-ascFB 工程菌能否以纤维二糖为唯一碳源生长，并尝试测出OD600生长曲线。

### Design

验证 *ascF*（膜转运蛋白）和 *ascB*（胞内 β-葡萄糖苷酶）在 MG1655 中共表达后，能否赋予工程菌以纤维二糖为唯一碳源生长的能力。同时尝试建立 OD600 生长曲线，检测细菌生长速率和趋势，省去CFU逐次涂板的繁琐操作。

实验分四组：

| 组别   | 菌株                      | 碳源         | 目的              |
| ---- | ----------------------- | ---------- | --------------- |
| 实验组  | MG1655 (pGEX-ascFB)     | 纤维二糖 5 g/L | 验证纤维二糖利用能力      |
| 阳性对照 | MG1655 (pGEX-ascFB)     | 葡萄糖 5 g/L  | 验证菌株活力与质粒无毒性    |
| 阴性对照 | MG1655 (pGEX-Empty, EV) | 纤维二糖 5 g/L | 验证底盘菌本身不能利用纤维二糖 |
| 空白对照 | MG1655 (pGEX-Empty, EV) | 葡萄糖 5 g/L  | 验证工程菌代谢压力       |

### Build

各菌株先培养至对数期，离心收集菌体，用无碳源M9洗涤2-3次以去除残留碳源，重悬并调至OD600=0.1接种。接种的同时进行梯度稀释涂板，作为t=0的活菌基数。接种后置于37°C恒温摇床震荡培养，每12h取样一次，用光度计测定OD600，记录直到od值进入稳定期。每个OD采样点同步取样。

实验发现，工程菌并未表现出优于空载对照（EV）的纤维二糖代谢能力；相反，由于质粒额外搭载了 ascB、ascF 两个蛋白的表达负担，工程菌在纤维二糖条件下的生长略弱于 EV。阳性对照（葡萄糖）生长正常，说明菌株活力与质粒本身无问题；空白对照 OD 无变化，排除污染。

### Learn

1. 功能层面：ascF、ascB 中至少有一个蛋白没有正确发挥功能，工程菌未获得纤维二糖利用能力，需要进一步确认是蛋白未表达还是未正确折叠/定位 → 进入蛋白胶验证。
2. 方法层面：OD–CFU 同步测定在本实验体系中不可行，后续实验仅以 OD600 变化表征细菌生长趋势，不再追求绝对活菌数。

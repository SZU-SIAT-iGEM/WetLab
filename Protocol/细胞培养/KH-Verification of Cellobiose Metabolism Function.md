# 纤维二糖代谢功能验证（生长曲线测定）

**实验目的：** 验证 *ascF* 和 *ascB* 基因在 MG1655 中表达后，能否赋予菌株利用纤维二糖作为唯一碳源生长的能力。

## **耗材**

- **培养基：** M9 最低盐培养基（共 1 L）：磷酸氢二钠 6.78 g，磷酸氢二钾 3 g，氯化钠 0.5 g，氯化铵 1 g，七水合硫酸镁 0.12 g，氯化钙 0.011 g；碳源按分组加入：纤维二糖 5 g 或葡萄糖 5 g。
- **菌株与质粒：**
  - 实验组：MG1655 (pGEX-ascFB)
  - 阳性对照：MG1655 (pGEX-ascFB) + 葡萄糖
  - 阴性对照：MG1655 (pGEX-Empty) + 纤维二糖
  - 空白对照：无菌培养基
- **耗材：** 96 孔板、枪头、封口膜。

## **仪器**

- 恒温摇床
- 酶标仪（用于测 \(OD_{600}\)）或分光光度计

## **实验流程**

1. **培养基配制**
   1. 配制 M9 基础培养基：先加 **Na₂HPO₄**，再加 **KH₂PO₄**，最后加 **NaCl** 和 **NH₄Cl**；使用磁力搅拌器充分搅匀，必要时轻度加热（<60℃）帮助溶解。
   2. 高压灭菌；待冷却后在超净台加入灭菌的 1 mL 1 M MgSO₄ 和 0.1 mL 1 M CaCl₂。
   3. 现配纤维二糖溶液，过滤灭菌后加入；不足 1 L 部分用超纯水补足。
   4. 设置分组培养基：实验组为 M9 + 纤维二糖（工程菌）；阳性对照为 M9 + 葡萄糖（工程菌）；阴性对照为 M9 + 纤维二糖（空载体菌）；空白对照为无菌 M9 + 纤维二糖（不接种细菌）。

2. **菌株接种**
   1. 各菌株培养至对数期。
   2. 离心收集菌体。
   3. 用不含碳源的 chemotaxis buffer 或 motility buffer 洗涤 2–3 次。
   4. 重悬并调至实验计划使用的 \(OD_{600}=0.1\)。
   5. 立即进行梯度稀释涂板（1:100）。

3. **生长曲线测定**
   1. 将接种好的平板或摇瓶放入恒温摇床，在 37°C 震荡培养。
   2. 每隔一定时间（每 2 小时或 4 小时），使用光度计测定 \(OD_{600}\)。
   3. 记录数据直至生长进入稳定期（通常 12–24 小时）。

4. **数据分析与预期结果**
   1. 绘制生长曲线：Time vs \(OD_{600}\)
   2. 预期结果：实验组（pGEX-ascFB + 纤维二糖）\(OD_{600}\) 随时间显著上升，说明菌株能利用纤维二糖生长；阳性对照（pGEX-ascFB + 葡萄糖）正常快速生长，验证菌株本身活力及质粒无毒性；阴性对照（空载体 + 纤维二糖）\(OD_{600}\) 基本不增长或增长极慢，说明 MG1655 本身不能利用纤维二糖；空白对照 \(OD_{600}\) 无变化，排除培养基污染或沉淀干扰。

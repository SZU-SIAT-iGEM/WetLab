# MG1655 内源 chb 启动子替换pKD46 / λ-Red 基因组编辑

# 将 pKD46 导入 MG1655

## 材料

MG1655 感受态、pKD46、LB、Amp (100 μg/mL)、2M glucose

## 仪器

金属浴，摇床，培养箱

## Protocol

1. 使用实验室现有 MG1655 感受态。
2. 按实验室已验证的标准质粒转化流程导入 pKD46。
3. 转化后常规复苏。
4. 涂布 **LB + Amp 100 μg/mL**。
5. **30°C** 倒置培养过夜。
6. 第二天检查应获得 AmpR 单克隆，建议挑 2–4 个独立克隆分别扩增，并留备份。

# λ-Red 诱导 + 新鲜电转感受态制备

## 材料

arabinose母液，LB、Amp (100 μg/mL)

## 仪器

摇床，冰盒，Nanodrop分光光度计

## Protocol

1.培养 MG1655/pKD46单克隆接种到Amp（100 μg/mL）+LB的液体培养基，30°C，200–250 rpm振荡培养

2.OD600≈0.1–0.2 加入 arabinose至终浓度10 mM诱导

3.OD600 达到约 **0.4–0.6** 后，立即将菌液放冰上 **10–15 min**预冷

# 电转感受态细胞制备

## 材料

冰冷无菌 ddH2O、冰冷 10% (v/v) glycerol、预冷离心管、预冷电转杯

## 仪器

4°C 离心机、冰盒/冰水浴、移液器

## Protocol

1. 当诱导培养物 OD600 达到约 **0.4–0.6** 后，立即将菌液置于冰上 **10–15 min**。
2. 在 **4°C，4,000–6,000 × g，10 min** 条件下离心收菌。
3. 完全弃去上清。
4. 用约原培养体积 **1/2–1 倍**的冰冷无菌 ddH2O 轻柔重悬细胞。
5. 在 **4°C，4,000–6,000 × g，10 min** 条件下再次离心。
6. 再用冰冷无菌 ddH2O 重复洗涤 **1 次**。
7. 用冰冷 **10% glycerol** 洗涤 **1 次**。
8. 最后用少量冰冷 **10% glycerol** 重悬，使细胞高度浓缩。
9. 分装为 **40–50 μL/管**。
10. 感受态细胞尽量立即用于 donor DNA 电转；从开始收菌起全程保持 **0–4°C**。

---

# Donor DNA 电转

## 材料

高纯度线性双链 donor DNA、0.1 cm 或 0.2 cm 电转杯、SOC 培养基

## 仪器

电转仪、冰盒、移液器

## Protocol

1. 预冷电转杯。
2. 取 **40–50 μL** 新鲜电转感受态细胞。
3. 加入 **100–300 ng** 纯化后的线性 donor DNA。
4. 轻柔混匀，避免产生气泡。
5. 将混合液转入预冷电转杯。
6. 根据电转杯 gap 使用匹配参数：
   - **0.1 cm cuvette**：1.8 kV，25 μF，200 Ω。
   - **0.2 cm cuvette**：2.5 kV，25 μF，200 Ω。
7. 完成脉冲后立即加入约1% 2M glucose的 LB培养基。
8. 将全部细胞转移至无菌培养管中。

---

# 电转后恢复

## 材料

1% 2M glucose的 LB

## 仪器

37°C 摇床

## Protocol

1. 电转后立即将细胞置于约 **1 mL 1% 2M glucose的 LB** 中恢复。
2. 在 **37°C，200–250 rpm** 条件下振荡培养 **2 h**。
3. 恢复完成后进入 Kan 平板筛选。

---

# Kan 平板筛选

## 材料

LB 固体培养基、Kanamycin 50 μg/mL

## 仪器

37°C 培养箱

## Protocol

1. 将恢复后的菌液涂布在 **LB + Kan 50 μg/mL** 平板上。
2. **37°C** 倒置培养约 **16–24 h**。
3. 次日观察菌落形成情况。
4. 若出现独立菌落，挑取候选克隆进入后续 PCR 验证。

---

# 候选克隆 PCR 验证

## 材料

候选 KanR 菌落、PCR 引物、高保真或常规 PCR 体系

## 仪器

PCR 仪、琼脂糖凝胶电泳系统

## Protocol

1. 从 Kan 平板上挑取 **6–12 个**独立菌落进行初筛。
2. 进行左 junction PCR：
   - 一条 primer 位于 donor 左侧之外的基因组区域；
   - 另一条 primer 位于 Kan 或 CP12 内部。
3. 进行右 junction PCR：
   - 一条 primer 位于 donor 内部；
   - 另一条 primer 位于 donor 右侧之外的基因组区域。
4. 进行 whole-locus PCR：
   - 两条 primer 均位于 donor 两侧之外；
   - 用于区分 WT 与 edit，并检查是否存在异常大小片段。
5. 对 PCR 结果符合预期的克隆进行扩增培养并准备测序。

---

# Sanger 测序验证

## 材料

PCR 阳性克隆、测序 PCR 产物或基因组 DNA、Sanger 测序引物

## 仪器

无

## Protocol

1. 选择 junction PCR 与 whole-locus PCR 均符合预期的阳性克隆。
2. 准备适合送测的 PCR 产物或测序模板。
3. 测序覆盖：
   - 左 junction；
   - FRT/Kan 区域；
   - CP12；
   - CP12 与 chb 下游连接区域；
   - 右 junction。
4. 将测序结果与预期 edited locus 序列比对。
5. 只有在插入边界和 CP12 序列均正确时，才确认该克隆为目标工程菌。

# pKD46 curing 检查

## 材料

无抗 LB、LB + Amp 平板

## 仪器

37°C 培养箱、摇床

## Protocol

1. 将已经确认发生基因组编辑的菌株在**无 Amp**条件下培养。
2. 优先使用 **37°C** 进行非选择培养，以促进温敏 pKD46 丢失。
3. 培养后稀释并获得单克隆。
4. 将同一克隆分别点种至：
   - LB+Kan；
   - LB + Amp。
5. 选择 **LB+Kan 生长、LB + Amp 不生长** 的克隆。
6. 将该克隆作为已经 curing pKD46 的工程菌继续保存和实验。

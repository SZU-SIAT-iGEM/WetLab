# 实验目的，实验原理与实验概述

## 实验目的：

利用改良硬琼脂塞法证明工程菌具有会对纤维二糖产生趋向性，同时进行定量分析

## 实验原理：

无色、水溶性的氯化三苯基四氮唑（TTC）可被存活的大肠杆菌还原为红色、不溶性的三苯基甲臜（TPF）。TTC可以随着时间在琼脂中缓慢扩散，而TPF在琼脂中固定，因此红色沉淀的深浅与局部细菌数量正相关。在趋化性测定中，TTC与化学诱导物共同掺入硬琼脂塞，随诱导物向周围扩散。细菌在趋化作用下向塞子附近聚集，还原TTC生成TPF，塞周红色区的强弱指示细菌聚集程度，据此判断其对该诱导物的趋向性。因TPF对细菌具有微弱毒性，实验观测时间应适当控制。

## 实验概述：

### 实验一：验证大肠杆菌对纤维二糖的趋化功能

1. 实验组的设计：

   | 菌株  | 塞子                     | 平板1号    | 平板2号                    |
   | ----- | ------------------------ | ---------- | -------------------------- |
   | ascBF | 一定浓度的纤维二糖的塞子 | 低营养平板 | 无营养平板（验证后可补充） |

2. 对照组的设计：

   1. 菌株对照
        | 菌株                             | 目的                       |
        | -------------------------------- | -------------------------- |
        | 野生的大肠杆菌                   | 空白对照                   |
        | 空载质粒的大肠杆菌               | 验证是否为质粒的干涉       |
        | 鞭毛被破坏的大肠杆菌（后续补充） | 验证是主动趋化还是被动吸附 |
        | 缺失ascB基因的大肠杆菌           | 验证缺少ascB基因后的情况   |
        | 缺失ascF基因的大肠杆菌           | 验证缺少ascF基因后的情况   |

   2. 塞子对照

        | 塞子                                         | 目的                                                       |
        | -------------------------------------------- | ---------------------------------------------------------- |
        | 空白塞子                                     | 空白对照                                                   |
        | 加入等量葡萄糖的塞子                         | 验证其趋化功能是否正常（正常情况下大肠杆菌会对葡萄糖趋向） |
        | 加入等量其他类型的（菌株无法利用的）糖的塞子 | 排除其他糖类的干扰                                         |
        | 加入等渗无机盐的塞子                         | 排除渗透压的干扰                                           |




### 实验二：定量分析不同浓度纤维二糖对大肠杆菌趋化效果

配置5种不同浓度的纤维二糖塞子，进行实验

# 耗材

## 消耗的材料：

琼脂粉，TTC溶液，PBS溶液，纤维二糖溶液，葡萄糖溶液，蔗糖溶液，山梨醇，胰蛋白胨

## 需要制备的溶液：

•     PBS缓冲液：pH 7.4；
	配方：NaCl：8 g/L；KCl：0.2 g/L；Na₂HPO₄：1.44 g/L；KH₂PO₄：0.24 g/L
•     PBS-琼脂溶液：4% (w/v)
•     半固体琼脂：0.6%
•     TTC（2,3,5-三苯基氯化四氮唑，Sigma-Aldrich）：1% (w/v) 储备液

------
# 仪器

打孔机，离心仪，培养箱等

# 实验流程

## 实验一：

### 制备HAP硬脂塞：

1. 制备PBS-琼脂溶液（4% (w/v)，PH 7.4），预热至80°C左右[^1]
2. 向其中补充1% TTC(w/v) 储备液（琼脂溶液：TTC = 12：1）[^2]
3. 将溶液分为5分，每份7.5mL，分别加入不同试剂（PBS-琼脂-TTC混合溶液：试剂 = 1：1），并做好标记
   | 溶液     | 浓度 |
   | -------- | ---- |
   | 无       | /    |
   | 纤维二糖 | 50mM |
   | 葡萄糖   | 50mM |
   | 蔗糖     | 50mM |
   | 山梨醇   | 50mM |
4. 充分混合后分别倒入60 mm × 15 mm培养皿中，等待其凝固
5. 用8 mm打孔器制备硬琼脂塞（HAP），放好备用

### 制备菌落平板+进行趋化实验（低营养组）

1. 收集菌体，用PBS（pH 7.4）重悬，加入一定量的M9培养基成分（0.1%），调整细胞悬液至OD₆₀₀ = 0.4-0.6[^3]
2. 将12.5 mL 0.6%琼脂（**严格控制在50°C**）与12.5mL细菌细胞悬液混合
3. 将混合物**快速**倒入预先放置了HAP的150 mm × 15 mm培养皿中（HAP放置在距平板边缘1.5 cm处）塞子等距离分布在培养皿边缘（**小心别冲散预放置的塞子**）[^4]
4. 室温放置冷却10分钟，在微需氧条件下培养
5. 分别在 10、20、30、60 min 拍照记录；
6. 平行做3次实验，对照
7. 取其他菌体，按照上述步骤进行对照实验

### 制备菌落平板+进行趋化实验（无营养组）

1. 收集菌体，用PBS（pH 7.4）重悬，调整细胞悬液至OD₆₀₀ = 0.4-0.6[^3]
2. 将12.5 mL 0.6%琼脂（**严格控制在50°C**）与12.5mL细菌细胞悬液混合
3. 将混合物**快速**倒入预先放置了HAP的150 mm × 15 mm培养皿中（HAP放置在距平板边缘1.5 cm处）塞子等距离分布在培养皿边缘（**小心别冲散预放置的塞子**）[^4]
4. 室温放置冷却10分钟，在微需氧条件下培养
5. 分别在 10、20、30、60 min 拍照记录；
6. 平行做3次实验，对照
7. 取其他菌体，按照上述步骤进行对照实验

## 实验二

### 制备HAP硬脂塞：

1. 制备PBS-琼脂溶液（4% (w/v)，PH 7.4），预热至80°C左右[^1]
2. 向其中补充1% TTC(w/v) 储备液（琼脂溶液：TTC = 10：1）[^2]
3. 将溶液分为5分，每份7.5mL，分别加入不同浓度的试剂（PBS-琼脂-TTC混合溶液：试剂 = 1：1），并做好标记
   | 纤维二糖浓度 | 加入量 |
   | ------------ | ------ |
   | 10mM         | 7.5    |
   | 30mM         | 7.5    |
   | 50mM         | 7.5    |
   | 70mM         | 7.5    |
   | 100mM        | 7.5    |
4. 充分混合后分别倒入60 mm × 15 mm培养皿中，等待其凝固
5. 用8 mm打孔器制备硬琼脂塞（HAP），放好备用

### 制备菌落平板+进行趋化实验

1. 收集菌体，用PBS（pH 7.4）重悬，调整细胞悬液至OD₆₀₀ = 0.4-0.6[^3]
2. 将7.5 mL 0.6%琼脂（**严格控制在50°C**）与7.5mL细菌细胞悬液混合
3. 将混合物**快速**倒入分别预先放置了HAP的90 mm × 15 mm培养皿中（共5个）（HAP塞放置在平板中心）
4. 室温放置冷却10分钟，在微需氧条件下培养
5. 分别在 10、20、30、60 min 拍照记录；
6. 平行做3次实验，对照

[^1]: 原文献为100°C，担心损坏所以下调至80°C左右
[^2]: 引用文献数据，文献数据为0.5mL TTC 加入至7mL PBS-琼脂，担心显色不明显改为10：1
[^3]: 参考文献数据
[^4]: 文献内容为共计15mL加入至90mm x 15mm培养皿，但由于本实验需要同时放置多个塞子，因此同时扩大了5/3倍

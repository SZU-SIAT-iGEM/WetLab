# WetLab
作为SZU-SIAT-iGEM2026的湿实验仓库，存放实验报告、记录、数据，以及实验流程Protocols等。

## 用途说明
存放 **所有湿实验相关** 的内容，包括实验方案（Protocol）、原始数据、实验日志、结果分析等。这是 Wiki 撰写和项目答辩的重要素材来源，也是衡量团队生物学实践程度的重要指标。

## Protocol
### Protocols提交规范
我参考了toulouse团队的Wiki做了一版protocol已上传github，湿实验同学以后可以按照这个模板来上传文件。

**1.格式要求**
一级标题：该实验名字
二级标题：材料，仪器，protocol
下设1.2.3.4.…小点，或者视实验复杂程度增加其他元素（如表格）

**2.需要中文英文双语版本**

3.文件命名加上你的**名字首字母**如：YH-Experiment name.（意味着**本protocol未来可能的勘误和修改由你全权负责**）

### Protocol 分类
根据实验内容选择你要提交去哪个文件夹，参考内容如下：

```
Protocols/
├── 📁 分子克隆/           # PCR、酶切、连接、转化等
├── 📁 检测与分析/         # Western、SDS-page、酶活测定等
├── 📁 微生物操作/         # 灭菌、划线、保种等
├── 📁 微重力实验/         # 待补充
└── 📁 其他/               # 未分类的Protocol
```

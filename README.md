### 操作指南

#### Protocols 管理

| 操作 | 步骤 |
|------|------|
| **新增 Protocol** | 1. 在对应分类文件夹中创建文件<br>2. 使用 `templates/Protocol模板.md`<br>3. 命名格式：`Protocol_名称_v1.0.md`<br>4. 更新 `Protocol索引.md` |
| **更新 Protocol** | 1. 复制原文件并增加版本号（如 v1.0 → v1.1）<br>2. 在文件内注明修改内容<br>3. 保留旧版本不删除（数量较多时可以创建旧版本文件夹） |
| **引用 Protocol** | 在实验数据的 README 中写明使用的 Protocol 版本 |

#### 实验数据管理

**创建实验数据文件夹**：

1. 进入 `实验数据/YYYY-MM/` 文件夹
2. 创建新文件夹，命名格式：`YYYY-MM-DD_实验名称_操作者/`
3. 在文件夹内创建以下结构：
   ```
   YYYY-MM-DD_实验名称_操作者/
   ├── 📁 原始数据/      # 仪器直接导出的文件
   ├── 📁 处理后数据/    # 经过处理的数据
   ├── 📁 图像/          # 实验相关图片
   └── 📄 README.md      # 使用模板填写
   ```
4. 使用 `templates/实验数据README模板.md` 填写说明

#### 实验日志

- **记录时机**：每天实验结束后
- **命名格式**：`YYYY-MM-DD_实验日志.md`
- **内容要求**：记录当天所做实验、观察、问题、思考（例，可增减并根据具体情况调整）
